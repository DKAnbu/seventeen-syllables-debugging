One haiku about debugging in the 5-7-5 shape — a [make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) entry.

## The haiku

> Red dot on line nine
> the code stops, holding its breath
> my own typo grins

73 characters, three lines, 5-7-5 syllables (17 total). A breakpoint stops the program — and the bug turns out to be the author's own typo, grinning back.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the haiku to `/output/entry.txt`, after checking the gate locally (3 lines, 5-7-5 syllables, 1-200 characters, valid UTF-8, no control characters, no trailing whitespace).
